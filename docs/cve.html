    -

    • 숫자를 누르면 같은 조건의 CVE 목록이 열립니다. 화면의 숫자와 목록 건수는 같습니다.
    • 각 항목은 출처에서 확인된 경우에만 '있음'으로 표시합니다. 출처에 정보가 없으면 '미확인'으로 두고 '없음'과 구분합니다.
    • 여러 지표를 합친 위험 점수는 만들지 않습니다.
    • '최근 7일'은 데이터 기준일을 포함한 7일입니다. KEV 등재일은 CISA KEV 카탈로그 값을 씁니다.

        제품 수명주기

        제품 버전별 지원 일정과 그 버전에 연결된 CVE

        • 지원 상태는 제품 버전의 상태이며 CVE의 위험도가 아닙니다. CVSS나 EPSS와 합산하지 않습니다.
        • 날짜와 단계는 endoflife.date 값을 그대로 옮깁니다. 값이 없으면 '-'로 두고 추정하지 않습니다.

        데이터 출처

        • 출처마다 제공하는 정보, 추적 중인 CVE 가운데 '있음'으로 기록한 건수, 마지막으로 받은 시각을 보여 줍니다.
        • 출처가 언급하지 않은 CVE는 '없음'이 아니라 '미확인'입니다.
        • 출처별 이용 · 재배포 · 표기 조건은 하단 '데이터 출처 및 라이선스' 표에 한 번만 적습니다.

        출처

        범위는 추적 중인 CVE 가운데 그 출처가 '있음'으로 기록한 건수입니다.

        신호별 확인 현황

        신호마다 있음 · 없음 · 미확인 건수입니다.

        출처 간 차이

        출처끼리 값이 다른 경우입니다. 누르면 목록이 열립니다.

        데이터 범위와 점검

        파일별 생성 시각과 점검 결과입니다. 경고는 데이터끼리 맞지 않는 경우, 정보는 원래 비어 있는 값입니다.
