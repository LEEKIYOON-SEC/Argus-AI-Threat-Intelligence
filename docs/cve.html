    대시보드

    -

    • 숫자를 누르면 같은 조건의 CVE 목록이 열립니다. 화면의 숫자와 목록 건수는 같습니다.
    • 각 항목은 출처에서 확인된 경우에만 '있음'으로 표시합니다. 출처에 정보가 없으면 '미확인'으로 두고 '없음'과 구분합니다.
    • 여러 지표를 합친 위험 점수는 만들지 않습니다.
    • '최근 7일'은 데이터 기준일을 포함한 7일입니다. KEV 등재일은 CISA KEV 카탈로그 값을 씁니다.

        제품 수명주기

        제품 버전별 지원 일정

        • endoflife.date가 다루는 제품 전체의 버전별 지원 일정입니다. 날짜와 단계 이름은 그대로 옮기고, 값이 없으면 '-'로 둡니다.
        • 상태는 오늘 날짜로 계산합니다. ACTIVE 기본 지원 · SECURITY 보안 지원 · EXTENDED EOL 뒤 확장 지원(유료 포함) · EOL 지원 종료 · UNKNOWN 날짜가 없거나 제조사 단계 이름으로 정할 수 없음.
        • "90일 안에 EOL"은 EOL 날짜가 내일부터 90일 안에 오는 버전이 있는 제품입니다. 오늘이 EOL인 버전은 이미 EOL로 봅니다.
        • CVE와 연결한 지원 상태는 CVE 상세에서 보여 줍니다.

        데이터 출처

        • '기록 있는 CVE'는 추적 중인 CVE 가운데 그 출처에 기록이 있는 건수입니다. 출처에 기록이 없는 CVE는 '없음'이 아니라 '미확인'으로 봅니다.
        • '예약 주기'는 Argus가 출처에서 데이터를 다시 받도록 걸어 둔 주기입니다. CVE 목록과 대시보드의 데이터는 매시 18분에 예약된 작업이 내보낼 때 바뀝니다.
        • 익스플로잇 원문(Exploit-DB · PoC)과 점검 템플릿(nuclei)은 싣지 않고 링크만 둡니다. 탐지 룰 본문은 룰마다 작성자와 라이선스를 함께 적습니다.

        예약은 GitHub Actions 기준이라 GitHub 부하에 따라 늦게 시작하거나 건너뛸 수 있어, 실제 간격은 이보다 깁니다. 화면에 반영된 시각은 제목 옆 '기준' 시각입니다.
